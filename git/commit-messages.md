# Commit messages

- Follow **Conventional Commits**: `<type>: <description>`.
- Common types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`.
- **Every commit references its ticket** (see [tickets & traceability](../tickets/traceability.md)).
  Keep messages in English (see [writing conventions](../writing-conventions.md)).
